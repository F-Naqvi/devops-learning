# DevOps Engineering Portfolio

A hands-on learning repository documenting my progression in DevOps engineering, cloud infrastructure, automation and containerisation.

The repository contains practical exercises, guided assignments and projects developed while building my technical knowledge and applying concepts through implementation.

## Areas of Focus

### AWS
Practical cloud infrastructure assignments covering:

- VPC networking, public and private subnets, NAT Gateways and Bastion Hosts
- Application Load Balancers and multi-AZ deployments
- S3 static website hosting, CloudFront, Route 53 and ACM
- Serverless architecture using Lambda, API Gateway and DynamoDB

[Explore AWS assignments](./aws/)

### Bash & Linux
Developing Linux administration and shell scripting skills through:

- Bash fundamentals, variables, loops, functions and error handling
- File operations, automation and scripting exercises
- Bash Battle Arena scripting challenges
- OverTheWire Bandit Linux security exercises

[Explore Bash](./bash/) · [Explore Linux](./linux/)

### Docker
Containerisation and multi-container application development, including:

- Dockerfiles and image building
- Docker Compose and container networking
- Flask application containerisation
- Redis persistence and NGINX load balancing

[Explore Docker](./docker/)

### Git
Hands-on Git exercises covering version control, repository management and common Git workflows.

[Explore Git Lab](./git-lab/)

### Terraform
Infrastructure as Code exercises covering:

- Basic Terraform configuration
- Resource creation using `count`
- Resource creation using `for_each`
- Functions including `coalesce`, `lookup` and `try`
- Reusable EC2 modules

[Explore Terraform](./terraform/)

## Learning Approach

I focus on understanding how infrastructure and services work, implementing them practically, troubleshooting problems and documenting the decisions and lessons learned along the way.

This repository is continuously evolving as I progress through my DevOps journey.
